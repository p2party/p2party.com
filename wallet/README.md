# P2PARTY browser wallet

This first-party wallet is served at `/wallet/`. Its archive format, native signature verification, checkpoint replay and browser forms come from the [portable wallet at 073aa16](https://github.com/p2party/p2party-server/tree/073aa16f0051bbb3e542833657e097a4640b17c6/clients/evm/portable-wallet). The original Apache 2.0 license is included here. The site adapts navigation, public-history synchronization and optional balance display. Changes to the upstream cryptographic protocol and fixtures should be reviewed alongside this copy.

`npm run build:wallet` creates the standalone page and integrity-pinned local assets. It also builds `/wallet/restore-wallet.html`, a self-contained downloadable wallet, and its SHA-256 manifest. The web and native builds run this step automatically.

The signing document loads no general application scripts. Its content security policy denies network connections. A dedicated worker reads public history only after a visitor chooses to sync. The wallet checks every streamed receipt on the device before counting it. Only a stream request and acknowledgments of public block heights are sent to the worker. The offline document embeds the signing code and never starts a worker. Choosing to share a checked balance saves only its amount and height in this tab’s session storage. Encrypted archives are saved to local storage only when the visitor opts in.

`npm run test:wallet` restores fresh backups generated by the Node companion at commit 073aa16, including both native suites and legacy receive folders. The reference producer under `tests/companion/` keeps its original archive encoder independent of the web implementation. The tests also verify checkpoint replay and offline payment recovery. Set `P2PARTY_WALLET_VERIFIER` to a local native verifier executable to cross-check signed transfers.
